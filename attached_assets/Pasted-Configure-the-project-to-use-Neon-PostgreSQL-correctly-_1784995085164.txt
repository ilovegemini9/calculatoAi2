Configure the project to use Neon PostgreSQL correctly for both development and production.

DO NOT break any existing functionality.

==================================================
DATABASE CONFIGURATION
==================================================

Use Neon PostgreSQL as the only database.

Use environment variables only.

Never hardcode credentials.

Production:
Use DATABASE_URL.

Development:
Use DATABASE_URL from local environment.

==================================================
PRISMA
==================================================

If Prisma is not installed:

- Install prisma
- Install @prisma/client
- Initialize Prisma

Create or update:

prisma/schema.prisma

Datasource:

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url = env("DATABASE_URL")
}

Generate Prisma Client.

Verify Prisma connects successfully to Neon.
