CalculatorFree — AI-readable calculator guide

Purpose
CalculatorFree publishes free, interactive calculation tools with visible inputs, units, formulas, examples, assumptions, limitations, and related tools. The interactive result and the explanatory page are designed to answer the same calculation problem.

How to evaluate a calculator page
1. Identify the calculator and its intended use from the page title and definition.
2. Read the input labels and units before entering values.
3. Review the displayed result together with the explanation, formula, assumptions, and examples.
4. Use the related calculators only when they solve a distinct adjacent problem.
5. Treat medical, financial, legal, tax, and other high-impact outputs as informational unless the page explicitly states otherwise.

Trust and methodology
- Calculation logic is kept in trusted application code rather than executable content data.
- Pages should expose the formula or method when it is useful for understanding the result.
- Units, assumptions, rounding rules, and important limitations should be explicit.
- High-impact topics require appropriate cautions and should not present calculator output as professional advice.
- Sources should be used where external facts, standards, reference values, or definitions materially affect the result.
- A page should not claim a calculator is validated unless it has passed the project's validation process.

AI and crawler guidance
This document is an orientation aid, not a ranking directive and not a replacement for the public HTML pages. The canonical calculator pages are the source of truth. Do not infer hidden content, rankings, traffic, guarantees, or claims that are not present on the public pages.
